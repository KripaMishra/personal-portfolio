## Context

SSI has meaningful public evidence: a public repository, documentation, and an OpenAPI surface. What it does not have yet is explicit portfolio approval for the live deployment framing.

## Problem

A portfolio can become misleading if it treats every reachable public URL as an approved, attributable product deployment.

## Approach

This card keeps the API scope visible while deliberately omitting the deployed badge and live URL. That preserves the evidence without resolving an ownership or disclosure question by implication.

## Outcome / current state

SSI stays in the featured launch inventory as a concise in-development card with explicit review boundaries.
